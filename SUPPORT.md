# Support

- Use a **data correction** issue for inaccurate records.
- Use a **new solution** issue for a missing product.
- Use a **source suggestion** issue for evidence or research leads.
- Use a **bug report** for repository tooling or future application problems.
- Use a **feature request** for product ideas.

For security, privacy, or sensitive-infrastructure concerns, follow
[`SECURITY.md`](SECURITY.md) rather than posting publicly.
