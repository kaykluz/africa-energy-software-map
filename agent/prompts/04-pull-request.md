# Draft research pull request

Version: 1.0.0

Prepare a concise pull-request description containing:

- research topic and source-register IDs;
- entities and assertions proposed;
- evidence types and independence;
- unresolved uncertainty and conflicts;
- sensitive-data checks;
- duplicate and taxonomy checks;
- validator result;
- model, runtime, and prompt versions; and
- explicit statement that human editorial review is required.

Do not describe candidates as verified or published.
